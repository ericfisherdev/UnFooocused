# Jira Issue Standards

## Task Structure

Every Jira Task must have the following sections:

1. **Description:** A comprehensive description of what is to be achieved.
2. **Implementation Plan:** A technical explanation of how to achieve the task.
3. **Acceptance Criteria:** A list of testable criteria to determine if the task is finished or not.

## Epic Structure

Every Jira Epic must have the following sections:

1. **Description:** A detailed description of what the epic will achieve once completed.
2. **Acceptance Criteria:** A thorough acceptance criteria that should be reached by creating the tasks within the epic.
